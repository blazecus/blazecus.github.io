Particles/Fluids
MPM particle simulation

Fluids and particles will be a fairly important feature in the final game, so I wanted to start working on them early. Here I replicated an MPM implementation to do some testing and see how easy it would be to fit into the engine. Will take a lot of work to make it more stable and actually helpful ingame.

For now though, I am going to work on something that might take a couple months. Instead of doing manual animations, I am planning on making the character built out of rigidbodies, and teaching it how to run with reinforcement learning, much like a robot. This will have to be done for every enemy type as well, but I'm hoping that if I iron out the the process early, it will be fairly straightforward to do in the future. There are a lot of tools for this for the purpose of robotics, so while it will be challenging, I think it's very doable, and it will make the game seem a lot more simulated as a result.
